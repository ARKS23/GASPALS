# 项目目标

## 游戏方向

本项目暂定名为 `ARK`，目标是在 GASPALS 的移动、动画、Traversal、相机和 Overlay 基础上，开发一个第三人称动作塔防游戏。

当前短期目标不是直接做完整塔防，而是先完成“玩家持枪射击”的基础战斗原型。射击、命中、伤害、死亡、UI 和反馈稳定后，再逐步加入敌人波次、基地核心、防御塔、建造和资源系统。

## 基本定位

- 类型：第三人称动作塔防
- 模式：优先单人
- 视角：第三人称
- 战斗方式：玩家亲自移动、瞄准、射击，同时布置防御设施
- 风格：偏动作射击和防守生存，暂不追求硬核军事模拟
- 核心体验：流畅移动、清晰射击反馈、敌人波次压迫、防御设施布置、守住核心目标

## 核心玩法设想

玩家在关卡中保护一个核心目标，例如基地、电源、传送门或防御核心。敌人会按波次从出生点进攻核心，玩家既可以亲自使用枪械作战，也可以消耗资源建造炮塔、陷阱、墙体或其他防御设施。

基础循环：

1. 准备阶段：玩家观察路线、布置防御、补充弹药。
2. 进攻阶段：敌人按波次进攻核心。
3. 战斗阶段：玩家移动、射击、修理或调整防线。
4. 奖励阶段：击杀敌人或守住波次后获得资源。
5. 强化阶段：升级武器、防御塔或角色能力。

## 第一阶段目标

第一阶段只验证玩家战斗手感：

- 保留 GASPALS 原有移动、跳跃、蹲伏、奔跑、Traversal 和动画系统。
- 创建自己的 ARK 角色子类。
- 实现基础持枪、瞄准、开火、换弹。
- 使用射线检测实现第一版武器命中。
- 增加简单血量、伤害、死亡逻辑。
- 增加简单准星、弹药和生命值 UI。
- 创建测试目标，验证命中和扣血。

## 第二阶段目标

第二阶段开始接近塔防核心：

- 创建敌人基础类。
- 敌人能够沿 NavMesh 移动到基地核心。
- 创建基地核心，拥有生命值。
- 敌人靠近基地核心后攻击核心。
- 实现简单波次管理器。
- 玩家击杀敌人获得资源。

## 第三阶段目标

第三阶段加入防御设施：

- 创建可建造物基础类。
- 创建第一种自动炮塔。
- 炮塔自动搜索敌人并攻击。
- 玩家可以消耗资源放置炮塔。
- 增加建造预览、合法放置检测和简单建造 UI。

## 暂不处理

- 多人合作
- 大型关卡流程
- 完整装备成长
- 复杂背包系统
- 大量武器和防御塔
- 高级敌人 AI
- 复杂剧情任务
- 重写 GASPALS Motion Matching 数据库

## 技术原则

- GASPALS 负责角色运动、动画、Traversal、相机和 Overlay。
- ARK 负责战斗、武器、敌人、塔防、资源、建造和游戏规则。
- 后续开发优先使用 C++ 实现 ARK 的核心 Gameplay 逻辑。
- 蓝图主要负责继承、配置、动画接入、UI、关卡摆放和表现层。
- 不把射击和塔防逻辑直接堆进 GASPALS 原始蓝图。
- 优先通过 C++ 基类、Actor Component、DataAsset、接口和子蓝图扩展。
- 玩家武器、防御塔攻击、敌人伤害应尽量复用同一套伤害和生命值系统。

## C++ 和蓝图分工

GASPALS 项目基础是蓝图和动画资产，但 ARK 自己的长期玩法系统尽量使用 C++ 搭建。这样可以保持逻辑清晰，方便复用、调试和后期扩展。

建议分工：

- C++：角色扩展基类、战斗组件、武器组件、生命值组件、武器基类、武器数据、敌人基类、基地核心、波次管理、防御塔、建造物、资源系统。
- 蓝图：`BP_ARKCharacter`、具体武器蓝图、具体敌人蓝图、具体防御塔蓝图、UI Widget、动画 Montage、音效、VFX、关卡实例。
- DataAsset：武器数值、防御塔数值、敌人配置、波次配置。

推荐第一批 C++ 类：

- `AARKCharacter`
- `UARKCombatComponent`
- `UARKWeaponComponent`
- `UARKHealthComponent`
- `AARKWeaponBase`
- `UARKWeaponDataAsset`
- `AARKEnemyBase`
- `AARKDefenseCore`
- `AARKWaveManager`
- `AARKBuildableBase`
- `AARKTurretBase`

短期可以先让 `BP_ARKCharacter` 继承 GASPALS 的 `CBP_SandboxCharacter`，然后挂载 C++ 组件。不要一开始重写 GASPALS 的移动和动画系统。

## 原型成功标准

- 进入 PIE 后，角色可以正常移动并使用 GASPALS 原有能力。
- 玩家可以装备步枪、瞄准、开火、换弹。
- 开火可以命中测试目标并造成伤害。
- 测试目标生命值归零后死亡。
- 后续可以自然扩展出敌人、波次、基地核心和防御塔。
