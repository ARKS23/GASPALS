# 武器动画表现开发方案

## 1. 目标与边界

补齐开火、换弹、装备和卸装的动画表现，同时保持现有职责：

- `WeaponBase`：管理开火、换弹状态、计时和弹药结算。
- `WeaponPresentationComponent`：把 Gameplay 事件转换为动画、音效等表现指令。
- `BP_PlayerCharacter`：复用 GASPALS Overlay 和 AnimInstance 播放具体 Montage。
- Anim Notify：处理弹匣显隐、局部音效、抛壳等表现，不直接修改弹药。

弹药结算不能只依赖 Anim Notify。后续联机或无动画角色仍需要由 Gameplay 计时可靠完成换弹。

## 2. 当前问题

- `WeaponBase` 已有 `OnReloadStarted`、`OnReloadFinished`，但取消换弹没有独立事件。
- `ReloadSound` 仍由 `WeaponBase::PlayReloadFeedback()` 直接播放，未进入表现层。
- `WeaponDataAsset` 已有 `FireMontage`、`ReloadMontage`、`EquipMontage`，目前尚未形成统一调用链。
- 换枪、卸装、死亡或关闭战斗时，需要可靠停止旧 Montage 和残留表现。

## 3. 推荐事件流

```text
成功开火
WeaponBase.OnWeaponShot
-> WeaponPresentationComponent
-> Fire Animation Cue
-> BP_PlayerCharacter 播放 FireMontage

开始换弹
WeaponBase.OnReloadStarted
-> WeaponPresentationComponent
-> Reload Started Cue + ReloadSound
-> BP_PlayerCharacter 播放 ReloadMontage

换弹完成/取消
WeaponBase.OnReloadFinished / OnReloadCanceled
-> WeaponPresentationComponent
-> Reload Stop Cue
-> BP_PlayerCharacter 收口 Montage 和临时弹匣表现
```

## 4. 开发步骤

### 步骤 1：补齐 Gameplay 事件

修改：

```text
Source/GASPALS/Weapons/WeaponBase.h
Source/GASPALS/Weapons/WeaponBase.cpp
```

1. 新增 `OnReloadCanceled` 和对应蓝图事件。
2. `CancelReload()` 只在真实状态变化时广播一次取消事件。
3. 装备切换、卸装和 EndPlay 统一经过取消流程。
4. 从 `WeaponBase` 移除直接播放 `ReloadSound` 的旧逻辑。

### 步骤 2：扩展表现组件

修改：

```text
Source/GASPALS/Weapons/WeaponPresentationTypes.h
Source/GASPALS/Weapons/WeaponPresentationComponent.h
Source/GASPALS/Weapons/WeaponPresentationComponent.cpp
```

新增统一动画指令，例如：

```cpp
enum class EWeaponAnimationCueType : uint8
{
    Fire,
    ReloadStarted,
    ReloadFinished,
    ReloadCanceled,
    Equipped,
    Unequipped
};
```

表现组件负责：

- 切换武器时完整解绑旧武器的射击和换弹事件。
- 成功射击才广播 `Fire`，空仓和射速限制不播放动画。
- 换弹开始时播放基础换弹声音并广播动画指令。
- 完成、取消、卸装和 EndPlay 时广播对应收口指令。
- Montage 为空时安全跳过，不影响 Gameplay 状态。

### 步骤 3：蓝图接入 GASPALS

修改：

```text
BP_PlayerCharacter
DA_Rifle
```

1. `BP_PlayerCharacter` 初始化时只绑定一次表现组件的动画指令。
2. `Fire` 使用上半身或 Additive Slot，避免覆盖移动与持枪姿势。
3. `ReloadStarted` 播放 Reload Montage；`ReloadCanceled` 立即停止并恢复临时表现。
4. `Equipped/Unequipped` 与现有 Overlay 更新顺序一致，先准备视觉 Mesh，再播放动画。
5. 根据 Montage 原始长度和 `ReloadTime` 计算播放速率：

```text
PlayRate = MontageLength / ReloadTime
```

### 步骤 4：接入 Anim Notify

第一版只添加必要通知：

- `MagazineDetach`：隐藏枪上弹匣并显示手持弹匣。
- `MagazineAttach`：恢复枪上弹匣并清理手持弹匣。
- `ReloadSound`：弹匣拔出、插入、拉栓等局部声音。
- `ShellEject`：后续需要时接抛壳表现。

任何取消路径都必须执行一次统一清理，不能依赖后续 Notify 自动恢复。

## 5. 验收清单

- [ ] 半自动和全自动的每次成功射击只播放一次 Fire Montage。
- [ ] 空仓、射速限制和换弹期间不会播放 Fire Montage。
- [ ] Reload Montage、HUD 换弹状态和实际弹药结算时间一致。
- [ ] 换枪、卸装、死亡和关闭战斗可以中断换弹且不补弹。
- [ ] 快速装备/卸装不会收到旧武器动画回调。
- [ ] Montage 或声音资源为空时，开火和换弹逻辑仍正常。
- [ ] 弹匣临时 Mesh 在完成和所有取消路径中都能正确清理。

## 6. 推荐顺序

1. 补齐 `OnReloadCanceled`。
2. 迁移 `ReloadSound` 到表现组件。
3. 建立统一 Animation Cue。
4. 接入 Fire、Reload、Equip Montage。
5. 最后增加弹匣和局部音效 Notify。
