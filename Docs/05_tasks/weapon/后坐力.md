# 后坐力、动态散布与准心开发方案

## 1. 目标与边界

建立一致的射击手感，并严格区分三类数据：

- Gameplay 散布：由 `WeaponBase` 计算，决定真实射线方向。
- 镜头和武器后坐力：纯表现，由角色蓝图和动画系统消费。
- 动态准心：只显示 Gameplay 状态，不参与命中计算。

蓝图不能重新计算散布，准心大小也不能反向决定射线方向。

## 2. 当前基础

- `WeaponBase::ApplySpreadToDirection()` 目前使用固定 `SpreadAngle + VRandCone`。
- `FWeaponShotEvent.AimDirection` 已保存本次射击的实际方向。
- `FCrosshairHUDState` 当前只有可见性、战斗状态和瞄准状态。
- `WBP_Crosshair` 已能显示固定准心，但尚无扩张和恢复。

## 3. 数据设计

第一版在 `WeaponDataAsset` 增加：

```text
HipBaseSpread            腰射基础散布角
AimBaseSpread            瞄准基础散布角
SpreadPerShot            每次成功射击增加值
MaxSpread                最大散布角
SpreadRecoveryDelay      停火后开始恢复的延迟
SpreadRecoveryRate       每秒恢复角度
MovementSpreadMultiplier 移动倍率
AirborneSpreadMultiplier 滞空倍率

RecoilPitchMin/Max       单发镜头上跳范围
RecoilYawMin/Max         单发水平偏移范围
RecoilReturnSpeed        镜头回正速度
```

现有 `SpreadAngle` 在迁移期作为 `HipBaseSpread` fallback，数据资产更新完成后再删除，避免一次性破坏旧武器。

新增只读状态：

```cpp
struct FWeaponAccuracyState
{
    float CurrentSpreadDegrees;
    float MinSpreadDegrees;
    float MaxSpreadDegrees;
    float NormalizedSpread;
    bool bIsAiming;
};
```

## 4. 开发步骤

### 步骤 1：实现动态散布

修改：

```text
Source/GASPALS/Weapons/WeaponDataAsset.h
Source/GASPALS/Weapons/WeaponBase.h
Source/GASPALS/Weapons/WeaponBase.cpp
```

1. `WeaponBase` 保存当前射击扩散值，只有成功射击才累加。
2. 每次射击前组合基础、连续射击、移动、滞空和瞄准修正。
3. 使用短周期 Timer 只在需要恢复时更新，不常驻 Tick。
4. 状态变化时广播 `OnAccuracyStateChanged`，UI 不轮询武器。
5. 换弹、卸装和停止战斗时停止恢复 Timer；是否立即复位由武器配置决定。

实际散布建议使用 `ShotSequence` 派生随机种子和 `FRandomStream`，为回放与后续联机校正保留确定性。

### 步骤 2：生成后坐力指令

修改：

```text
Source/GASPALS/Weapons/WeaponPresentationTypes.h
Source/GASPALS/Weapons/WeaponPresentationComponent.h
Source/GASPALS/Weapons/WeaponPresentationComponent.cpp
```

每次成功射击生成一次 `FWeaponRecoilCue`，至少包含：

```text
Pitch
Yaw
ShotSequence
```

`WeaponPresentationComponent` 只广播指令，不直接修改 Controller 或 Camera。空仓、换弹和射速限制不会产生后坐力。

### 步骤 3：角色蓝图应用镜头与武器后坐力

修改：

```text
BP_PlayerCharacter
角色 AnimBP / Fire Montage
```

- 镜头后坐力使用可恢复的目标偏移，不直接永久累加 Control Rotation。
- 武器后坐力使用 Additive 动画或 Overlay Slot，与镜头后坐力分离。
- 瞄准时可使用独立倍率，不能通过减少镜头动画偷偷改变 Gameplay 散布。
- 连续射击停止后平滑回正，玩家主动压枪输入应保留效果。

### 步骤 4：扩展准心状态

修改：

```text
Source/GASPALS/UI/CombatHUDTypes.h
Source/GASPALS/UI/CombatHUDWidgetBase.h/.cpp
WBP_Crosshair
```

在 `FCrosshairHUDState` 增加 `NormalizedSpread`。HUD 数据层订阅当前武器的 `OnAccuracyStateChanged`，换枪时先解绑旧武器。

`WBP_Crosshair` 只做视觉插值：

```text
CrosshairRadius = Lerp(MinRadius, MaxRadius, NormalizedSpread)
```

四条准心臂使用稳定的 Canvas Slot 尺寸，只修改位置或 Render Transform，避免布局尺寸随动画跳动。

### 步骤 5：接入移动、滞空和瞄准上下文

由角色/战斗层提供只读射击上下文：

```text
bIsAiming
PlanarSpeedNormalized
bIsFalling
```

`WeaponBase` 消费上下文计算真实散布，但不依赖具体角色蓝图类型。非角色武器（例如防御塔）可以使用默认上下文。

## 5. 验收清单

- [ ] 单发、连射、移动、滞空和瞄准产生可预测的散布差异。
- [ ] 准心扩张与真实散布同源，停止射击后平滑恢复。
- [ ] 每次成功射击只产生一次镜头和武器后坐力。
- [ ] 空仓、换弹和射速限制不会产生假后坐力或准心扩张。
- [ ] 相同随机种子和 ShotSequence 可以得到相同散布结果。
- [ ] 换枪后旧武器不再更新准心。
- [ ] 高低帧率下恢复速度和最终结果一致。
- [ ] 关闭准心或镜头表现不影响实际射线和伤害。

## 6. 推荐顺序

1. 先实现射击累加与时间恢复，不接移动和滞空。
2. 接入 `FWeaponAccuracyState` 和动态准心。
3. 接入镜头及武器后坐力。
4. 最后加入移动、滞空、瞄准倍率和确定性随机。
