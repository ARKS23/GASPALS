# 阶段性开发计划

## 总体路线

开发顺序遵循一个原则：先做玩家可操作的射击闭环，再做塔防系统。

不要一开始同时做武器、敌人、建造、资源、UI、升级和波次。每个阶段都应该有可测试的结果。

## 阶段 1：玩家射击原型

目标：玩家能使用枪械完成基础射击。

详细执行文档：[阶段 1：玩家射击原型详细计划](phase_01_shooting_prototype.md)

任务：

- [ ] 确认 ARK Gameplay 代码放在当前项目 C++ 模块，或后续独立 ARK 模块。
- [ ] 创建 `/Game/ARK` 内容目录。
- [ ] 创建 C++ 组件 `UARKCombatComponent`。
- [ ] 创建 C++ 组件 `UARKWeaponComponent`。
- [ ] 创建 C++ 组件 `UARKHealthComponent`。
- [ ] 创建 C++ 武器基类 `AARKWeaponBase`。
- [ ] 创建 C++ 武器数据资产 `UARKWeaponDataAsset`。
- [ ] 创建 `BP_ARKCharacter`，短期继承 GASPALS 的 `CBP_SandboxCharacter`。
- [ ] 将 C++ 组件挂到 `BP_ARKCharacter`。
- [ ] 保证 `BP_ARKCharacter` 的移动、跳跃、蹲伏、奔跑、Traversal 正常。
- [ ] 创建 ARK 输入：开火、瞄准、换弹。
- [ ] 创建步枪蓝图 `BP_ARKRifle`，继承 `AARKWeaponBase`。
- [ ] 创建步枪数据资产 `DA_ARKRifle`，基于 `UARKWeaponDataAsset`。
- [ ] 实现步枪 Hitscan 开火。
- [ ] 实现弹匣、备用弹药和换弹。
- [ ] 创建测试目标并支持扣血死亡。

验收标准：

- 玩家能移动、瞄准、开火、换弹。
- 射线能命中测试目标。
- 测试目标能扣血并死亡。
- 没有明显运行时蓝图报错。

## 阶段 2：射击反馈和 UI

目标：让射击行为有基本表现反馈。

任务：

- [ ] 装备步枪时切换 Rifle Overlay。
- [ ] 开火时播放枪口火光。
- [ ] 开火时播放音效。
- [ ] 命中时显示 Debug 命中点或命中特效。
- [ ] 添加准星 UI。
- [ ] 添加弹药 UI。
- [ ] 添加生命值 UI。
- [ ] 添加简单命中反馈。

验收标准：

- 玩家能清楚知道是否开火、是否命中、剩余多少弹药。
- 武器表现和逻辑状态一致。

## 阶段 3：敌人和基地核心

目标：从射击测试进入塔防雏形。

任务：

- [ ] 创建 C++ 敌人基类 `AARKEnemyBase`。
- [ ] 创建敌人蓝图 `BP_ARKEnemyBasic`，继承 `AARKEnemyBase`。
- [ ] 给敌人添加生命值组件。
- [ ] 敌人可以被玩家击杀。
- [ ] 创建 C++ 基地核心 `AARKDefenseCore`。
- [ ] 创建蓝图 `BP_ARKDefenseCore` 作为需要保护的目标。
- [ ] 敌人能沿 NavMesh 移动到基地核心。
- [ ] 敌人靠近核心后攻击核心。
- [ ] 核心生命值归零后判定失败。

验收标准：

- 敌人会主动向核心移动。
- 玩家可以击杀敌人。
- 如果不防守，敌人能摧毁核心。

## 阶段 4：波次系统

目标：形成基础防守节奏。

任务：

- [ ] 创建 C++ 波次管理器 `AARKWaveManager`。
- [ ] 创建蓝图 `BP_ARKWaveManager` 用于关卡配置。
- [ ] 创建敌人出生点。
- [ ] 配置每波敌人数量和间隔。
- [ ] 波次结束后进入短暂准备阶段。
- [ ] 击杀敌人获得资源。
- [ ] UI 显示当前波次和剩余敌人。

验收标准：

- 敌人能按波次生成。
- 波次有开始和结束。
- 玩家能通过击杀获得资源。

## 阶段 5：第一种防御塔

目标：加入塔防建造的核心元素。

任务：

- [ ] 创建 C++ 可建造物基类 `AARKBuildableBase`。
- [ ] 创建 C++ 防御塔基类 `AARKTurretBase`。
- [ ] 创建蓝图 `BP_ARKTurretBasic`，继承 `AARKTurretBase`。
- [ ] 炮塔自动搜索范围内敌人。
- [ ] 炮塔自动攻击敌人。
- [ ] 炮塔攻击复用伤害系统。
- [ ] 玩家可以消耗资源放置炮塔。
- [ ] 添加简单放置预览。

验收标准：

- 玩家可以建造炮塔。
- 炮塔可以自动攻击敌人。
- 炮塔能帮助玩家守住核心。

## 阶段 6：可玩原型整合

目标：形成一个小型可重复游玩的 Demo。

任务：

- [ ] 制作一张小型测试关卡。
- [ ] 设置敌人路线。
- [ ] 设置 3 到 5 个波次。
- [ ] 增加基础胜利和失败条件。
- [ ] 调整玩家武器、敌人血量、核心血量和炮塔伤害。
- [ ] 清理 Debug 逻辑。

验收标准：

- 玩家可以从开始防守到胜利或失败。
- 射击、敌人、波次、资源、炮塔能形成完整闭环。
- 后续可以继续扩展武器、防御塔、敌人类型和关卡。

## 当前优先级

当前只执行阶段 1。

最小目标：

1. C++ 战斗、武器、生命值组件能编译并挂到角色上。
2. 玩家角色继承 GASPALS 并能正常移动。
3. 玩家能装备步枪。
4. 鼠标左键可以开火。
5. Hitscan 能命中测试目标。
6. 测试目标能扣血死亡。
